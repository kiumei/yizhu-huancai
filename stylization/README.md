# 风格训练与模型导出

负责人：路杰然。

本目录用于维护风格复现、训练和模型导出代码，后续补充实际实现。

## 输入与输出

- 输入：明确版本的图像、相机、写实模型与来源清楚的风格参考。
- 输出：基础风格模型、导出脚本、属性说明、训练与推理记录。
- 检查点和模型保存在 `outputs/` 或团队共享存储。

## 阶段任务

第一阶段先用公开示例验证一种风格，并将导出模型交给网页模块实际加载。第二阶段再接入自采校史馆场景。

交接时说明位置、尺度、旋转、不透明度和颜色表示，记录点数、点顺序、几何与坐标变化。风格参考、代码版本、参数、导出命令和已知问题一并归档。

局部保护与区域标记的接口见 `region_protection/README.md`。
