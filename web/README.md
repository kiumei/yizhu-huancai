# 网页展示与导览

负责人：夏廷翰。

本目录用于建立网页工程，目前先约定接入和验收要求，后续提交实际代码与启动命令。

## 实施顺序

1. 使用 Three.js 与成熟高斯渲染组件加载公开示例。
2. 实现观察、缩放或移动、复位，以及加载和失败提示。
3. 接入自采写实模型与风格示例，检查属性兼容性。
4. 统一坐标与显示变换，实现写实和风格模型同视角切换。
5. 增加三个知识热点、图文卡片和一条约 2—3 分钟的路线。
6. 检查约定电脑与手机，记录加载、切换、帧率和异常。

实际采用的渲染组件、版本、依赖安装和开发命令在代码加入时补充。Spark 可作为候选组件，是否采用以实际验证为准。

网页代码与小型界面素材纳入 Git；高斯模型通过共享存储获取，放到实际工程约定的本地资源目录。模型版本、变换和热点路线配置保持对应。
