# 实验评价与测试记录

许铭轩组织，各模块负责人提交实际结果。本目录后续存放评价脚本和可复核的记录。

## 评价范围

- 写实质量：固定视角与路径中的缺失、漂浮物和重点展陈辨识度。
- 风格与保护效果：基础风格与保护版本在相同视角下比较，记录改善、边缘问题与代价。
- 网页性能：首屏、可交互时间、帧率、切换、加载失败与资源释放。
- 用户试用：任务完成、操作卡点、知识理解及改进后的新用户复测。
- 复现：另一名成员按说明运行预处理、网页、区域工具及重建小样。

每条结果说明模型版本、设备、浏览器、分辨率、网络与缓存条件。预期指标与实测结果分开记录；大体积图片和视频放到 `outputs/` 或共享存储。
