## 模型输入与坐标对齐配置

配置统一维护于 `configs/viewer_models.json`，测试模型复制自 `outputs/` 至 `web/public/models/`：

| 模型 ID | 本地文件 | 来源版本与点数 | 坐标变换 | 初始相机（位置 → 目标） |
| --- | --- | --- | --- | --- |
| `capture01_v1` | `web/public/models/capture01_v1.splat` | `capture01_v1 / 10000 步`（464,680 点） | `rot(180, 0, 0)°`, `pos(0,0,0)` | `[-9.5, 0.4, 6.2]` → `[-2.2, -1.6, -1.2]` |
| `public_broche` | `web/public/models/example-broche-rose-gold.splat` | 公开原版示例（129,929 点） | `rot(0, 0, 180)°`, `pos(0,2,0)` | `[-0.35, 0.9, -2.15]` → `[-0.25, 0.78, 0.45]` |
| `style_vangogh` | `web/public/models/vangogh_broche.splat` | `output梵高风.splat`（129,669 点） | `rot(0, 0, 180)°`, `pos(0,2,0)` | `[-0.35, 0.9, -2.15]` → `[-0.25, 0.78, 0.45]` |

- **自采坐标系对齐说明**：COLMAP 重建世界 `-Y` 向上，绕 X 轴旋转 `180°` 后在 Three.js `+Y` 向上坐标系中直立，书架、天花板风扇、灯管、桌面及窗景朝向正常。
- **公开/风格模型对齐说明**：采用 `rot(0,0,180)°` 与 `pos(0,2,0)`（与 SuperSplat 录屏一致），相机设于 `-Z` 正面机位直对花朵正立展示并避开左侧 HUD 面板。
