# 位姿解算与写实重建

负责人：李金华。

本目录用于维护 COLMAP、3DGS 的运行脚本、参数与模型清理工具，后续补充实际代码。

## 输入与输出

- 输入：筛选图像、来源清单、人工复核及训练检验划分。
- 输出：相机内外参、稀疏重建、写实高斯模型、训练配置及缺陷记录。
- 原始数据放在 `data/`，重建与模型产物放在 `outputs/`。

## 交付要求

记录所用实现的来源链接、代码版本、依赖、GPU、训练命令与参数。模型交给网页模块，训练数据结构交给风格模块。注明坐标、尺度、模型属性和输入版本；保留基准模型及补拍建议。

普通点云与训练后的高斯模型需分别说明格式。接收者实际打开结果后，将检查结论记入 `docs/handoffs/`。
